# TangoPunk Arcade

TangoPunk Arcade and Patcher for Windows x64.

[Download the latest release](https://github.com/TangoBunny/TangoPunk-Arcade/releases/latest) for the combined Arcade + Patcher package, an update for an existing installation, and the matching source code.

## Getting started

Extract the full Windows package to a writable folder and run `Start Arcade.cmd` or `Start Patcher.cmd`. Use **Supported ROMs** on the title screen to check required game and firmware files. `Open ROMs folder.cmd` opens the package's ROMs folder.

Games and firmware must be provided by the user. Release packages contain no game ROMs, BIOS, OS disks, supporter keys, saves or personal settings.

## Source code

The release provides a separate emulator/application source base and a small application source update. Download both named source assets and follow their build instructions. The latest release notes identify the matching versions. GitHub's automatically generated repository source ZIP/tar files are not the complete corresponding source download.
